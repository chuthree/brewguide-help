# Brew Guide Help

[Brew Guide](https://chu3.top/brewguide) 的[帮助文档](https://brewguide-help.chu3.top)，介绍冲煮、咖啡豆管理、笔记以及数据备份的使用方法。

## 一起完善

欢迎修正错字、补充步骤、更新截图，也欢迎添加新的教程。可以点击文章底部的「在 GitHub 编辑此页」提交修改，或在 Brew Guide 用户群中分享建议。

- [如何编辑与反馈](content/docs/contributing.md)：从反馈问题或修改一篇文章开始。
- [贡献指南](CONTRIBUTING.md)：编辑文章、添加教程和提交修改。
- [站点维护](docs/maintenance.md)：本地预览、项目结构与构建配置。

## 关于项目

文档默认使用 Markdown（`.md`）编写，需要交互组件的文章使用 MDX（`.mdx`）。站点基于 Next.js 与 Fumadocs 构建为静态页面，文章位于 `content/docs/`，图片位于 `public/brewguide-help/`。

本仓库尚未为文章和图片声明统一的开放许可证，转载或复用前请联系作者确认。
