通过 MCP 连接，可以让 Codex、WorkBuddy、Hermes 等工具查看和管理 Brew Guide 中的数据。

---

在 Brew Guide 桌面版中，进入 `设置` - `实验性功能`，开启 `启用 MCP 连接`。使用时请保持 Brew Guide 运行。

![实验性功能中的 MCP 连接设置](/brewguide-help/mcp-connection/enable.webp)

点击 `MCP 配置` - `更多设置`，选择允许访问的数据和权限。`查看与编辑` 包含新增、修改和删除。

![MCP 数据范围和权限选择](/brewguide-help/mcp-connection/permissions.webp)

返回后，点击 `连接配置` - `复制配置`。配置包含密钥，请只交给信任的工具；查询内容会交给连接的模型服务处理。

---

打开同一台电脑上的 Codex、WorkBuddy 或 Hermes，将复制的配置发给它，请它帮你完成 MCP 连接。

![向 AI 询问今天喝什么意式豆](/brewguide-help/mcp-connection/question-example.webp)

配置完成后，你可以试着对它说：

- “帮我添加并画一个 Chemex 咖啡壶”
- “帮我整理一下咖啡豆的信息”
- “帮我记录这次冲煮”
- “这支咖啡豆适合什么研磨度？”
- “这支咖啡豆怎么冲合适？”
