---
title: Supabase 实时云同步
module: 数据与备份
---

配置 Supabase 后，多台设备会自动保持实时同步，无需手动上传或下载。整个流程只需注册一个免费账号、运行一段初始化命令，再将两项配置信息填入 Brew Guide 即可。

> 注册与配置流程略繁琐。如果不熟悉，可联系 <InlineImagePreviewTag label="开发者" imageSrc="/contact/wechat.webp" imageAlt="微信二维码" /> 协助，只需提供邮箱用于注册和验证。

---

首先，注册 Supabase 并创建项目。

打开[注册页面](https://supabase.com/dashboard/sign-up)，填写邮箱和密码完成注册。

![Supabase 注册界面](/brewguide-help/realtime-cloud-sync/01-supabase-sign-up.webp)

进入邮箱，点击验证链接。

![邮箱验证界面](/brewguide-help/realtime-cloud-sync/02-email-verification.webp)

验证成功后，在 `Create a new organization` 页面点击 `Create organization`。

![创建组织界面](/brewguide-help/realtime-cloud-sync/04-create-organization.webp)

点击 `Generate a password` 自动生成数据库密码，再点击 `Create new project`。

![创建新项目](/brewguide-help/realtime-cloud-sync/05-create-project-generate-password.png)

等待项目创建完成，页面会自动进入 `Project Overview`。

![Project Overview 页面](/brewguide-help/realtime-cloud-sync/06-project-overview.webp)

---

接下来，初始化同步数据表并获取连接信息。

点击左侧 `SQL Editor`，将 <InlineTextPreviewTag label="SQL 命令" src="brewguide-help/sql/realtime-cloud-sync-init.sql" collapsedHeight={240} /> 中的内容完整复制粘贴进去，点击 `Run` 执行（这段命令会自动建好存放数据所需的表格，直接运行即可，无需看懂代码）。

![SQL Editor 执行命令](/brewguide-help/realtime-cloud-sync/07-sql-editor-run.webp)

执行完成后返回 `Project Overview`，点击标题下方的链接，复制并保存 `Project URL` 与 `Publishable Key`。

![获取 Project URL 与 Publishable Key](/brewguide-help/realtime-cloud-sync/08-project-url-and-key.webp)

---

最后，在 Brew Guide 中填入配置。

> 建议先通过 `导出数据` 手动备份一份当前数据，以防误覆盖。

点击左上角图标进入 `设置`，打开 `数据与备份`。

![进入设置](/brewguide-help/realtime-cloud-sync/09-open-settings.webp)

![进入数据与备份](/brewguide-help/realtime-cloud-sync/10-open-data-backup.webp)

在同步服务中选择 `Supabase 实时同步`。

![选择同步服务](/brewguide-help/realtime-cloud-sync/11-select-sync-service.webp)

将刚才保存的 `Project URL` 与 `Publishable Key` 填入对应输入框，等待自动同步完成即可。

![填写云同步配置](/brewguide-help/realtime-cloud-sync/12-enter-sync-config.webp)

首次同步建议先在已有数据的设备上完成配置，等自动上传完成后，再依次在其他设备填入相同配置。全部设备配置完成后，数据就会自动实时同步。
