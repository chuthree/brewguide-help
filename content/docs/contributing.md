欢迎一起完善 Brew Guide 的帮助文档。修正一个错字、补充一个步骤，或写一篇新的教程，都能帮助其他使用者。

## 反馈问题

在 Brew Guide 用户群中，发来文章链接和你的建议即可。遇到操作问题时，可以附上 App 版本和截图，方便我们了解情况。

## 修改文档

1. 点击文章底部的 **在 GitHub 编辑此页**，登录 GitHub。
2. 修改需要调整的文字，按页面提示保存，并简要说明修改原因。
3. 创建 **Pull Request**（修改申请），将修改发给我们。

提交后，我们会查看你的修改并更新文档。GitHub 如果提示创建副本（Fork），按提示操作即可。

想添加新教程，或需要更详细的编辑步骤？请查看[贡献指南](https://github.com/chuthree/brewguide-help/blob/main/CONTRIBUTING.md)。也欢迎先在群里分享草稿，一起完善。
